# Архив — не запускать

Эти два файла сохранены при сведении истории `main`. Они создают другую
структуру notifications и дублирующие triggers. Рабочая схема проекта
использует `006_notifications.sql` с `payload`; архивные файлы не входят
в последовательность миграций. Не копировать их в SQL Editor и не включать
в автоматический мигратор.
