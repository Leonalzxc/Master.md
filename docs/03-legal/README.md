# Юридические страницы MVP

Исторические продуктовые шаблоны; не копировать в публичный пилот как утверждённые документы.
Актуальные RU/RO черновики страниц и справки: `web/src/lib/pilot-copy.ts`.
Они описывают подготовленную release-версию, а не ещё не обновлённый production.

## Файлы

- `terms.md` — пользовательское соглашение.
- `privacy.md` — политика конфиденциальности.
- `moderation-policy.md` — правила модерации и запреты.
- `reviews-policy.md` — правила отзывов и споров.
- `refund-policy.md` — политика возвратов для платных услуг мастеров.

## Важно

Публичный запуск остаётся No-Go до подтверждения оператора, оснований обработки,
подрядчиков/передач, сроков хранения и рабочего процесса запросов пользователей.
Пилот бесплатный: шаблон refund-policy не является действующими условиями продажи.
Проверка документов и утверждение владельцем/юристом ещё не выполнены.
Список недостающих решений: `docs/pilot-legal-readiness.md`.
