# Сведение веток — 24.09.2026

Ветка `codex/stabilize-bids` сохраняет историю рабочего checkpoint
`5fb979c` и объединяет её с `origin/main` (`d940267`). Общая история
позволяет дальше готовить PR в `main`, не перенося изменения вручную между
двумя рабочими каталогами. Открытые старые PR автоматически не закрывались.

Решения по конфликтам:

- Сохранены новые права профилей, `ensureMyProfile`, RU/RO, поиск, страницы
  поддержки/верификации, CI и отказ от старого `/listings`.
- Сохранены текущие черновики цен и географии; merge не является одобрением
  тарифов, юридических текстов или публичного запуска.
- Из `main` перенесены сроки заявок 7/30 дней, переход к кредитам,
  настройки сохранения сессии, обработка ошибок webhook, миграции 012/013,
  ручное закрытие просроченных заявок администратором.
- Cookie refresh сохраняет `maxAge=0` при удалении cookie. Обновлённые
  cookies прикладываются также к redirect на авторизацию.
- Webhook использует существующий `server-only` admin client. Привязка
  Telegram через открытый UUID всё ещё требует отдельного исправления.
- В 012 устранено вложенное `$$`, ломавшее SQL. Вызов функции истечения
  доступен service role; server action сначала проверяет администратора.
  В 013 заблокированный администратор не проходит проверку `is_admin`.
- Дубли `004_notify_master_on_bid_selected.sql` и `005_notifications.sql`
  из `main` перенесены в `web/supabase/legacy/`: они описывают другую схему
  уведомлений (`link` вместо фактически используемого `payload`).
  **Не запускать их как миграции.** Дублирующие неиспользуемые React-компоненты
  уведомлений не перенесены; актуальный компонент находится в `layout/`.
- Настройки стороннего агента и изменённый gitlink рабочего каталога не
  перенесены. Они не нужны приложению.

Проверка: весь `npm run quality` пройден. Тесты приватности теперь также
исполняют 006, 011, 012 и 013 в PostgreSQL, чтобы выявлять SQL-ошибки и
возврат рекурсивных policies. Production SQL и deployment не выполнялись.

Это сведение кода не заменяет нормализацию всей истории миграций:
в старых файлах ещё остаются demo seed и legacy listings.
